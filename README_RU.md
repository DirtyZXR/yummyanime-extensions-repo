# Расширение YummyAnime для Aniyomi

Русское расширение для Aniyomi/Anikku (форк Tachiyomi) с аниме от YummyAnime (site.yummyani.me).

## Возможности

- ✅ Просмотр популярных аниме
- ✅ Просмотр последних обновлений
- ✅ Поиск аниме с фильтрами
- ✅ Просмотр деталей аниме
- ✅ Воспроизведение эпизодов с разными видеоплеерами
- ✅ Поддержка плееров Kodik, Sibnet, Alloha и YouTube
- ✅ Выбор качества видео
- ✅ Плеер по умолчанию
- ✅ Поддержка русского языка

## Версии расширения

### Текущая ветка: `rewrite-yummyanime-v2`

Содержит:

1. **Основной код** (YummyAnime.kt, YummyAnimeDto.kt, YummyAnimeFilters.kt) - Полный функционал с сериализацией JSON
2. **Тестовая версия** (YummyAnime_Test.kt) - Простая версия для проверки работоспособности
3. **Документация** - Полная документация на русском языке

### Инструкция по тестированию

#### Вариант 1: Тестовая версия (рекомендуется)

**Файл**: `YummyAnime_Test.kt`

Эта версия:
- Использует `HttpSource` вместо `AnimeHttpSource`
- Простая разборка HTML с помощью Jsoup
- Не требует сложной сериализации JSON
- Позволяет быстро проверить базовую функциональность

**Сборка для тестирования**:

Собрать APK из структуры monorepo:

```bash
cd yuzono/anime-extensions
./gradlew :src:ru:yummyanime:assembleRelease
```

**Установка в Aniyomi**:

1. Скачайте APK из релизов
2. Установите в Aniyomi/Anikku
3. Добавьте расширение
4. Протестируйте все основные функции:
   - Просмотр популярных аниме
   - Поиск аниме
   - Просмотр деталей аниме
   - Воспроизведение эпизодов

Если всё работает корректно - переходите к официальной интеграции!

#### Вариант 2: Основной код (официальная интеграция)

**Файл**: `YummyAnime.kt`

Эта версия:
- Полная функциональность с API YummyAnime
- Сериализация JSON с помощью kotlinx.serialization
- Следует всем рекомендациям yuzono/anime-extensions
- Поддержка всех видеоплееров

**Сборка для интеграции**:

Требуется сборка в репозитории yuzono/anime-extensions (см. docs/INTEGRATION_RU.md).

## Инструкция по сборке

### Требования

- Java 17 или выше
- Android SDK (API 34)
- Gradle 8.9

### Сборка из Monorepo (официальная интеграция)

Предпочтительный способ сборки - в репозитории yuzono/anime-extensions:

```bash
cd yuzono/anime-extensions
./gradlew :src:ru:yummyanime:assembleRelease
```

Вывод: `src/ru/yummyanime/build/outputs/apk/release/aniyomi-ru.yummyanime-v14.2.apk`

### Автономная сборка (для разработки)

Для автономной разработки требуется структура с библиотеками Tachiyomi core, которые недоступны.

## Установка

### В Aniyomi/Anikku

1. Скачайте APK из релизов
2. Откройте Aniyomi/Anikku
3. Перейдите в Настройки > Расширения
4. Нажмите "Установить из хранилища"
5. Выберите APK

### Через репозиторий

Добавьте URL этого репозитория в Aniyomi/Anikku:

```
https://raw.githubusercontent.com/DirtyZXR/yummyanime-extensions-repo/rewrite-yummyanime-v2/repo/index.min.json
```

## Настройки

### Параметры

Расширение поддерживает следующие параметры:

- **Предпочтительное качество**: Выберите качество видео (Любое, 1080p, 720p, 480p, 360p)
- **Плеер по умолчанию**: Выберите предпочитаемый видеоплеер (Любой, Kodik, Sibnet, Alloha, YouTube)

### Фильтры

- **Сортировка**: По популярности, рейтингу, дате, названию или просмотрам
- **Жанр**: Экшен, Приключения, Комедия, Драма, Фэнтези, Романтика, Хоррор, Сэйнен, Сёнэн, Сёдзё
- **Статус**: Все, Онгоинг, Завершен, Анонс
- **Год**: Фильтр по конкретному году

## Поддерживаемые видеоплееры

- **Kodik**: Стриминг высокого качества

## Интеграция

### Добавление в официальный репозиторий

Смотрите [INTEGRATION_RU.md](docs/INTEGRATION_RU.md) для подробных инструкций по интеграции этого расширения в официальный репозиторий yuzono/anime-extensions.

### Разработка

1. Следуйте рекомендациям по разработке расширений Tachiyomi/Aniyomi
2. Используйте `AnimeHttpSource` вместо `ParsedAnimeHttpSource`
3. Убедитесь, что все URL видео абсолютные
4. Используйте время UNIX Epoch для меток времени эпизодов
5. Возвращайте эпизоды в порядке убывания

## Устранение неполадок

### Расширение не работает

1. Проверьте совместимость версии Aniyomi/Anikku
2. Убедитесь в сетевом подключении
3. Попробуйте установить из репозитория вместо APK
4. Проверьте, доступен ли сайт YummyAnime

### Проблемы со сборкой

1. Убедитесь, что установлена Java 17
2. Проверьте путь к Android SDK
3. Проверьте версию Gradle
4. Попробуйте собрать в структуре monorepo
