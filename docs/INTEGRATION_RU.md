# Руководство по интеграции YummyAnime в официальный репозиторий

## Обзор

Это руководство объясняет, как интегрировать расширение YummyAnime в официальный репозиторий yuzono/anime-extensions.

## Текущий статус

- ✅ Структура кода соответствует официальным рекомендациям
- ✅ Отдельные файлы DTO (YummyAnimeDto.kt)
- ✅ Отдельный файл фильтров (YummyAnimeFilters.kt)
- ✅ Чистый основной файл (YummyAnime.kt)
- ✅ Готов для интеграции в yuzono/anime-extensions monorepo

## Шаги интеграции

### 1. Структура директорий

Создайте следующую структуру директорий в `yuzono/anime-extensions/`:

```
src/ru/yummyanime/
├── build.gradle
├── src/
│   └── eu/
│       └── kanade/
│           └── tachiyomi/
│               └── animeextension/
│                   └── ru/
│                       └── yummyanime/
│                           ├── YummyAnime.kt
│                           ├── YummyAnimeDto.kt
│                           └── YummyAnimeFilters.kt
└── res/
    ├── mipmap-mdpi/
    │   └── ic_launcher.png
    ├── mipmap-hdpi/
    │   └── ic_launcher.png
    ├── mipmap-xhdpi/
    │   └── ic_launcher.png
    ├── mipmap-xxhdpi/
    │   └── ic_launcher.png
    └── mipmap-xxxhdpi/
        └── ic_launcher.png
```

### 2. Создание build.gradle

Создайте `src/ru/yummyanime/build.gradle`:

```gradle
ext {
    extName = 'YummyAnime'
    extClass = '.YummyAnime'
    extVersionCode = 1
}

apply from: "$rootDir/common.gradle"
```

### 3. Подготовка исходных файлов

Скопируйте следующие файлы в `src/ru/yummyanime/src/eu/kanade/tachiyomi/animeextension/ru/yummyanime/`:

- `YummyAnime.kt` - Основной класс расширения
- `YummyAnimeDto.kt` - Объекты передачи данных
- `YummyAnimeFilters.kt` - Определения фильтров

**Примечание:** Исходные файлы уже имеют правильную структуру для monorepo. Изменения не требуются.

### 4. Ресурсы иконок

Расширению требуются квадратные иконки с закруглёнными углами в нескольких плотностях:
- mipmap-mdpi: 48x48 px
- mipmap-hdpi: 72x72 px
- mipmap-xhdpi: 96x96 px
- mipmap-xxhdpi: 144x144 px
- mipmap-xxxhdpi: 192x192 px

**Важно:** Удалите файлы `web_hi_res_512.png` из сгенерированных иконок.

### 5. Обновление основных файлов репозитория

#### a. Добавление в `settings.gradle.kts`

Добавьте расширение в настройки:

```kotlin
include(":src:ru:yummyanime")
```

#### b. Тестовая сборка

Соберите расширение из корня monorepo:

```bash
cd yuzono/anime-extensions
./gradlew :src:ru:yummyanime:assembleRelease
```

Вывод APK будет в:
`src/ru/yummyanime/build/outputs/apk/release/aniyomi-ru.yummyanime-v14.1.apk`

### 6. Проверка функциональности

Протестируйте расширение в Aniyomi/Anikku:

1. Установите APK
2. Добавьте расширение
3. Протестируйте просмотр популярных аниме
4. Протестируйте просмотр последних обновлений
5. Протестируйте функцию поиска
6. Протестируйте фильтры
7. Протестируйте просмотр деталей аниме
8. Протестируйте воспроизведение эпизодов с разными плеерами

## Рекомендации по коду, которые соблюдены

### ✅ Правильный базовый класс

Расширение использует `AnimeHttpSource` вместо устаревшего `ParsedAnimeHttpSource`.

### ✅ Правильная структура пакета

Пакет: `eu.kanade.tachiyomi.animeextension.ru.yummyanime`

### ✅ Обязательные поля

Все обязательные поля SAnime заполнены:
- `url` - Путь к аниме
- `title` - Название аниме
- `thumbnail_url` - URL обложки

### ✅ Метки времени эпизодов

`SEpisode.date_upload` использует время UNIX Epoch в миллисекундах.

### ✅ Абсолютные URL видео

Все URL видео преобразуются в абсолютные с помощью `toAbsoluteUrl()`.

### ✅ Порядок списка эпизодов

Эпизоды возвращаются в порядке убывания (сначала новые) с помощью `.reversed()`.

### ✅ Соглашение о версиях

Версия следует конвенции: `14 + extVersionCode` (например, v14.1 когда extVersionCode=1)

### ✅ Типы фильтров

Используются правильные типы фильтров:
- `AnimeFilter.Header` для информационного текста
- `AnimeFilter.Separator` для визуального разделения
- `AnimeFilter.Sort` для параметров сортировки
- `AnimeFilter.Select` для выпадающих списков
- `AnimeFilter.Text` для текстового ввода

### ✅ Зависимости

Используются только зависимости, доступные в monorepo:
- `kotlinx-serialization-json` для разбора JSON
- OkHttp для HTTP запросов
- Jsoup для разбора HTML (если требуется)

## Интеграция с API

### Базовый URL
- Основной: `https://site.yummyani.me`
- API: `https://site.yummyani.me/api/v1`

### Используемые endpoints

- `/api/v1/anime/popular` - Список популярных аниме
- `/api/v1/anime/updates` - Последние обновления
- `/api/v1/anime/search` - Поиск с фильтрами
- `/api/v1/anime/{slug}` - Детали аниме
- `/api/v1/anime/{slug}/episodes` - Список эпизодов
- `/api/v1/anime/{slug}/episodes/{id}/players` - Видеоплееры/ссылки

### Поддерживаемые видеоплееры

- **Kodik** - Извлекает URL из JSON паттерна
- **Sibnet** - Извлекает из JavaScript
- **Alloha** - Извлекает URL для разных качеств
- **YouTube** - Парсит ID видео
- **Прямые ссылки** - Резервный вариант через поиск по паттернам

## Устранение неполадок

### Ошибки сборки

**Ошибка:** "Unresolved reference 'animesource'"
**Решение:** Убедитесь, что сборка выполняется в yuzono/anime-extensions monorepo, а не автономно

**Ошибка:** "common.gradle not found"
**Решение:** Запустите сборку из корневой директории monorepo

### Ошибки во время выполнения

**Ошибка:** Расширение не видно в Aniyomi
**Решение:**
1. Проверьте, что код версии уникален
2. Убедитесь, что APK содержит всю необходимую метаданные
3. Протестируйте с версией Aniyomi debug для лучших сообщений об ошибках

**Ошибка:** Не удается воспроизвести видео
**Решение:**
1. Проверьте сетевое подключение
2. Убедитесь, что URL видео доступны
3. Протестируйте с разными видеоплеерами
4. Проверьте, не блокирует ли исходный сайт запросы
